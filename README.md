# Chinese Lunar Calendar for Todoist

A free, database-free Next.js App Router app. Configure one saved lunar event at a time, preview up to 20 Gregorian occurrences and explicitly create or update ordinary Todoist tasks. No cron, database, paid service, or automatic renewal.

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn/ui-style Button with CVA and shadcn component configuration, lunar-typescript, Zod, jose, Vitest and React Testing Library. The Button is locally maintained and intentionally has no Slot dependency.

## Local development

Use Node 22.14+ (or Node 24) and pnpm 11.25.0.

```bash
pnpm install --frozen-lockfile
cp .env.example .env.local
pnpm dev
```

Preview works without any credentials. OAuth/task sync requires the configuration below.

```bash
pnpm test
pnpm exec tsc --noEmit
pnpm lint
pnpm build
```

## Todoist OAuth

Register an application in https://developer.todoist.com/appconsole.html. Set the exact redirect URI to `https://YOUR-DOMAIN/api/auth/callback`; add `http://localhost:3000/api/auth/callback` for local testing. Configure the following server-only values in `.env.local` and Vercel environment settings:

- `APP_URL`: the canonical app origin, e.g. `https://YOUR-DOMAIN`.
- `TODOIST_CLIENT_ID` and `TODOIST_CLIENT_SECRET`: from Todoist's application console.
- `SESSION_SECRET`: a random secret generated by `openssl rand -hex 32`.

Never commit real credentials or use NEXT_PUBLIC_ variables for secrets. Redeploy after setting environment variables. Requests use Todoist API v1 and OAuth `data:read_write`; the app never asks users for a personal API token. Official reference: https://developer.todoist.com/api/v1/.

OAuth state is single-use with a 10-minute HTTP-only cookie. Access tokens are encrypted in an authenticated HTTP-only SameSite=Lax cookie (Secure in production). Mutating routes require the canonical Origin. Sessions expire at the earlier of the token expiry and seven days. This minimal implementation deliberately reconnects when the access token expires; it does not store or rotate refresh tokens. Newly registered Todoist apps may require reconnection after one hour. No token is exposed to browser JavaScript. Disconnect removes the local cookie; revoke access in Todoist to invalidate the grant.

## Recurrence and update rules

- Select a lunar month/day, ordinary or leap month only, a Gregorian start date and count (1–20).
- Missing leap months and day 30 are skipped rather than moved to another date. The search stops at lunar year 2100; fewer results are shown explicitly.
- Gregorian start years supported: 1901–2079. Default start date uses Asia/Shanghai.
- Each generated occurrence has a stable event UUID and slot index in its description. API request IDs help deduplicate retries.
- The browser stores this event's configuration and returned task IDs in localStorage. Updating changes title and due date on active tasks; description notes are preserved. Known IDs absent from Todoist's active task list are left alone, including completed/deleted tasks.
- Reducing count never deletes surplus tasks. Changing start date remaps the remaining active slots to the new preview dates.
- Keep the original browser data. Clearing storage, using another browser, concurrent submissions in multiple tabs, or losing a response before its IDs are saved can prevent reliable tracking. A database-free browser cannot provide global exactly-once creation. Review Todoist after a partial error and retry from the same browser.
- This initial UI stores one event configuration. It does not yet include an event collection, settings export/import, or cross-device sync.

## GitHub and Vercel setup on a Mac

If starting with this ZIP, extract it to `~/Projects/chinese-lunar-todoist`. Install GitHub CLI and Vercel CLI and authenticate:

```bash
brew install gh pnpm
npm install -g vercel
gh auth login
vercel login
cd ~/Projects/chinese-lunar-todoist
pnpm install --frozen-lockfile
pnpm test
pnpm build
git init -b main
git add .
git commit -m "Initial lunar Todoist app"
gh repo create chinese-lunar-todoist --public --source=. --remote=origin --push
vercel link --scope robertwangs-projects --project chinese-lunar-todoist
vercel git connect https://github.com/robertwang1001/chinese-lunar-todoist --scope robertwangs-projects
vercel --prod --scope robertwangs-projects
code .
```

Choose the existing Hobby scope; do not upgrade or provision a database. On first `vercel link`, accept creating the project if prompted. Configure the OAuth variables securely in Vercel's dashboard; do not put secret values in shell command arguments. Set APP_URL to the production URL and redeploy. Check the deployment in Vercel and connect Todoist for a real end-to-end test.

If the repository has already been created, clone instead:

```bash
mkdir -p ~/Projects
git clone https://github.com/robertwang1001/chinese-lunar-todoist.git ~/Projects/chinese-lunar-todoist
cd ~/Projects/chinese-lunar-todoist
pnpm install --frozen-lockfile
cp .env.example .env.local
code .
pnpm dev
```
